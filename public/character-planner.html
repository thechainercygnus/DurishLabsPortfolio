Character Planner

What should I chase next?

In World of Warcraft: Forever, the answer depends on what you already wear, which items you can equip at your level, and where those items come from. Character Planner brings that information together so you can decide what to do with your next play session.

First, find out what the API knows

The early work began with an undocumented Battle.net profile API. Some requests returned 404s, and the shape of the responses was still being worked out. The planner kept the raw responses and HTTP status codes from each sync, then used real captures to decide how to model character data. Those same snapshots made it possible to see how a character changed over time.

Read the original snapshot design decision

Turn a snapshot into a plan

Dungeon drops gave the planner a pool of items to compare with equipped gear. Ranking upgrades by slot made it possible to recommend dungeons based on the gear a character still needed. The planner grew to account for quest rewards, rare drops, and crafted gear, and added talent planning and a look ahead at upcoming levels.

Some information still had to come from inside the game. Character Planner Export fills those gaps by capturing bags, bank contents, and quest data for the planner to import.

Built like production software

Character Planner is a hobby project held to the standards I’d want at work:

  • Decisions on record. More than 60 short architecture decision records explain why each part works the way it does.
  • Every change checked. Each pull request runs the tests on SQLite and Postgres, type checks, browser and accessibility checks, and security scans (CodeQL, Semgrep, Trivy, secret scanning) before it can merge.
  • Trustworthy releases. Releases are container images for amd64 and arm64, signed with Sigstore, with an SBOM and build provenance.
  • Security in the open. It holds an OpenSSF Best Practices badge, and an assurance case sets out the threats and how the design counters them.

Run it for yourself or your guild

A self-hosted instance can sync your characters and track progress over time. Guild members can opt in to share what they still need, and guest mode gives recommendations by class and level without an account.
